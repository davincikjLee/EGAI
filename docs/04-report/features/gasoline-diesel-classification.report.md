## 1. 실험 배경

### 문제 정의
- 현재 데이터셋 2,484개가 모두 "정상" 중고차
- 실제 "고장" 엔진 데이터 부재로 OK/NG 분류 모델 직접 학습 불가
- 대안: 가솔린/디젤 차이를 "정상 vs 이상"의 대리 실험으로 활용

### 가설
1. 가솔린과 디젤 엔진은 물리적 특성이 다름 (점화 방식, 압축비, 음향 특성)
2. 이 차이가 스펙트로그램에서 학습 가능하다면, 향후 고장 데이터로도 분류 가능

### 데이터 현황
| 연료 타입 | 샘플 수 | 비율 |
|-----------|---------|------|
| 가솔린 | 2,402 | 92.4% |
| 디젤 | 197 | 7.6% |
| **불균형 비율** | **12.2:1** | |

## 2. 실험 1: VAE OOD Detection (비지도 학습)

### 실험 설계
- **방법**: 가솔린만으로 VAE 학습 후, 디젤이 OOD로 탐지되는지 평가
- **모델**: VAE (latent_dim=128, beta=0.5)
- **데이터**: 가솔린 500개 샘플 vs 디젤 197개 전체

### 결과

| 지표 | 가솔린 | 디젤 |
|------|--------|------|
| VAE 점수 평균 | 147.81 | 161.99 |
| VAE 점수 표준편차 | 27.81 | 24.35 |

| 통계 분석 | 결과 | 목표 | 판정 |
|-----------|------|------|------|
| Welch's t-test p-value | 1.08e-10 | < 0.001 | **PASS** |
| ROC-AUC | 0.6878 | > 0.70 | FAIL |
| Cohen's d | 0.5424 | > 0.5 | **PASS** |
| 디젤 분리율 (95% 초과) | 15.2% | > 50% | FAIL |

### 결론
- **부분적 성공 (2/4 기준 달성)**
- 통계적으로 유의미한 차이 존재
- 실용적 분류기로 사용하기엔 성능 부족

## 3. 실험 2: 이진 분류 (지도 학습)

### 실험 설계
- **방법**: CNN+CBAM 모델로 가솔린(0)/디젤(1) 직접 분류
- **모델**: BinaryCBAM (4채널 입력)
- **검증**: 5-Fold Stratified Cross-Validation
- **불균형 처리**: 클래스 가중치 (가솔린: 0.54, 디젤: 6.60)

| 2 | 0.8846 | 0.5522 | 0.3895 | 0.9487 | 0.9718 | 0.8781 |
| 3 | 0.9808 | **0.8718** | 0.8947 | 0.8500 | 0.9698 | 0.9304 |

| 5 | 0.9634 | 0.7957 | 0.6852 | 0.9487 | 0.9900 | 0.9366 |

### 최종 결과 (5-Fold 평균)

### 결론

- Recall 83%: 디젤(이상 대리)을 높은 확률로 탐지

## 5. 핵심 성과

### 검증된 사항
1. **스펙트로그램에서 연료 타입별 특징 존재**
   - ROC-AUC 0.97로 명확히 구분 가능

2. **현재 모델 구조(CNN+CBAM) 유효**
   - 4채널 스펙트로그램 입력이 효과적

3. **향후 OK/NG 분류 가능성 높음**
   - 실제 고장 데이터 확보 시 동일 구조 적용 가능

### 한계점
1. **디젤 ≠ 고장**: 연료 타입 차이가 고장 특성과 동일하진 않음
2. **불균형 문제**: 12:1 불균형으로 Fold별 편차 큼
3. **일반화**: 실제 고장 데이터로 재학습 필요
