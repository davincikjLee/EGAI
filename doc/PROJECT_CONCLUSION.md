## 프로젝트 본질 재정의

### 진짜 목적
> **"내가 사용할 엔진의 상태를 확인할 수 있는 모델 생성"**

### 현재까지 한 일
> **리버스 엔지니어링**: 현대차의 라벨링 데이터를 역으로 분석하여 품질 판단 기준 학습

## 핵심 결론 3가지

### 1. Autoencoder 기반 정상/이상 판별 모델

```
┌─────────────────────────────────────────────────────────┐
│                    현재 데이터의 본질                    │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  현대차 인증중고차 = 이미 "양호/정상" 판정받은 차량      │
│                                                         │
│  → 594개 전부가 "정상 엔진"의 표본                      │
│  → 이 데이터로 "정상의 경계"를 정의 가능                │
│                                                         │
│  활용 방안:                                             │
│  ┌─────────────────────────────────────────────┐        │
│  │  [정상 594개] → Autoencoder 학습            │        │
│  │        ↓                                    │        │
│  │  정상 패턴 압축/복원 능력 획득               │        │
│  │        ↓                                    │        │
│  │  [새 엔진 오디오] → 복원 시도               │        │
│  │        ↓                                    │        │
│  │  복원 에러 작음 = 정상 (현대차 기준 통과)    │        │
│  │  복원 에러 큼 = 이상 (주의 필요)            │        │
│  └─────────────────────────────────────────────┘        │
│                                                         │
│  가치: "현대차가 양호라고 판단할 수준인가?" 판별        │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 2. 라벨링 데이터 기반 품질 점수 예측 모델

```
┌─────────────────────────────────────────────────────────┐
│                  리버스 엔지니어링 성과                  │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  현대차 라벨링:                                         │
│  - mid_freq_score (중주파 품질)                        │
│  - low_high_freq_score (저고주파 균형)                 │
│  - audable_range_score (가청 범위)                     │
│  - regularity_score (규칙성)                           │
│  - irregularity_score (불규칙성)                       │
│                                                         │
│  우리가 학습한 것:                                      │
│  - 오디오 → 5개 점수 매핑 (MAE 0.48)                   │
│  - "현대차가 어떤 기준으로 점수를 매기는지" 역추론      │
│                                                         │
│  현재 한계:                                             │
│  - 정확도 100%는 아님 (±0.5점 오차)                    │
│  - 하지만 데이터가 쌓이면 정확도 향상 가능              │
│                                                         │
│  가치: 세부 항목별 진단 가능                            │
│  - "중주파는 양호하나 불규칙성 주의"                   │
│  - "저고주파 균형 개선 필요"                           │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 3. MP3 수집 데이터의 유효성

```
┌─────────────────────────────────────────────────────────┐
│                  데이터 수집 전략 검증                   │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  검증된 사실:                                           │
│  - 웹에서 크롤링한 MP3로 학습 가능                      │
│  - 현대차 라벨링과 오디오 패턴 상관관계 존재            │
│  - 데이터 증가 → 정확도 향상 (선형적 관계)              │
│                                                         │
│  수집 데이터 활용의 강점:                               │
│  ┌─────────────────────────────────────────────┐        │
│  │  1. 지속적 수집 가능 (웹 크롤링)            │        │
│  │  2. 라벨링이 이미 되어 있음 (현대차 제공)   │        │
│  │  3. 실제 차량 데이터 (시뮬레이션 아님)      │        │
│  │  4. 표준화된 녹음 조건 (현대차 프로토콜)    │        │
│  └─────────────────────────────────────────────┘        │
│                                                         │
│  새 데이터 호환성:                                      │
│  - 수집 데이터와 유사하게 가공하면 사용 가능            │
│  - 녹음 조건: 아이들 상태, 보닛 앞 30cm                 │
│  - 전처리: 16kHz 리샘플링, 5초 클립, STFT+HPSS         │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 리버스 엔지니어링의 가치

### 우리가 실제로 한 것

```
일반적 접근:
  데이터 수집 → 라벨링 정의 → 모델 학습
  (Forward Engineering)

우리의 접근:
  라벨링된 데이터 → 라벨링 기준 역추론 → 모델 학습
  (Reverse Engineering)
```

### 이것이 의미하는 바

```
┌─────────────────────────────────────────────────────────┐
│                  리버스 엔지니어링 성과                  │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  1. 현대차 품질 기준 해독                               │
│     - 어떤 주파수 특성이 중요한지                       │
│     - 규칙성/불규칙성을 어떻게 측정하는지               │
│     - 전문가 청음 평가의 수치화 방법                    │
│                                                         │
│  2. 전처리 파이프라인 표준화                            │
│     - STFT + HPSS 조합의 유효성 확인                    │
│     - 스펙트로그램 기반 학습 가능성 검증                │
│     - CNN + CBAM 구조의 효과 확인                       │
│                                                         │
│  3. 새 데이터 적용 가능성                               │
│     - 동일 조건으로 녹음하면 모델 적용 가능             │
│     - 라벨링 없이도 이상 탐지 가능 (Autoencoder)        │
│     - 점수 예측도 가능 (Regression)                     │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

├─────────────────────────────────────────────────────────┤

## 두 가지 모델의 역할

### Model A: Autoencoder (이상 탐지)

```
역할: 문지기 (Gatekeeper)
질문: "이 엔진이 정상 범위 안에 있는가?"
답변: 정상 / 이상

특징:
- 빠른 판단 (1차 스크리닝)
- 라벨 불필요
- 불량 데이터 없이도 동작

사용 시나리오:
"일단 이상 여부부터 확인"
```

### Model B: Regression (품질 점수)

```
역할: 평가사 (Evaluator)
질문: "이 엔진의 세부 품질 점수는?"
답변: 5개 항목별 점수

특징:
- 상세 진단
- 개선 포인트 제시
- 시계열 추적 가능

사용 시나리오:
"정상인데 어떤 부분이 약한지 알고 싶다"
```

### 통합 사용 흐름

```
[엔진 오디오 입력]
        ↓
┌─────────────────┐
│  Model A: 이상? │
└─────────────────┘
        ↓
    ┌───┴───┐
  이상      정상
    ↓         ↓
  🔴       ┌─────────────────┐
 정비소     │  Model B: 점수  │
 방문 권장  └─────────────────┘
                   ↓
            세부 점수 제공
            🟢🟡 관리 가이드
```

## 핵심 인사이트

### 1. 데이터의 본질

```
우리 데이터 = 현대차가 "양호"라고 판단한 엔진들
            = 정상의 기준점 (Reference)
            = Autoencoder 학습에 완벽한 데이터
```

### 2. 리버스 엔지니어링의 힘

```
라벨링 기준을 몰라도 → 데이터에서 패턴 학습
전문가 없이도 → 전문가 수준 판단 가능
새 데이터에도 → 동일 기준 적용 가능
```

### 3. 실용적 가치

```
Before: 정비소 방문 → 전문가 청음 → 주관적 판단
After:  스마트폰 녹음 → AI 분석 → 객관적 점수

비용: 무료
시간: 5초
접근성: 언제 어디서나
```
