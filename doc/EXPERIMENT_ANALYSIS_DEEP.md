## 2. 실험 변인별 해석

### 2.1 성공한 변인: CBAM Attention

```
Simple CNN (MAE 0.5635) → Simple+CBAM (MAE 0.4819)
                         ↓
                    -14.5% 개선
```

**왜 성공했는가?**

1. **파라미터 효율성**: CBAM은 약 24,000개 파라미터만 추가 (전체의 5%)
2. **정보 손실 없음**: 기존 CNN 구조 유지하면서 attention만 추가
3. **학습 목표 일치**: 스펙트로그램에서 "어디가 중요한지" 학습
4. **논문 검증**: 현대차 논문에서 회귀에 +8% 효과 보고 → 실제 +14.5%

### 2.2 실패한 변인들

#### (1) 추가 특징 (물리량, 메타데이터, 모듈레이션)

| 추가 특징 | 추가 파라미터 | MAE 변화 | 문제점 |
|----------|--------------|----------|--------|
| 물리량 14개 | ~50,000 | +40% 악화 | 과적합 |
| 메타데이터 14개 | ~30,000 | +51% 악화 | 과적합 |
| 모듈레이션 20개 | ~60,000 | +27% 악화 | 과적합 |

**왜 실패했는가?**

```
594개 샘플 ÷ 추가 파라미터 = 매우 낮은 샘플/파라미터 비율

규칙: 딥러닝은 파라미터당 최소 10~100개 샘플 필요
현실: 594개 ÷ 50,000 = 0.01 (극심한 부족)
```

**핵심 교훈**:
> "특징 추가 = 모델 복잡도 증가 = 더 많은 데이터 필요"

#### (2) Mel Spectrogram

```
STFT MAE: 0.54 → Mel MAE: 0.91 (+69% 악화)
```

**왜 실패했는가?**

1. **Mel 스케일은 음성용**: 인간 청각 특성 (Bark/Mel)은 음성 인식에 최적화
2. **엔진음은 기계음**: 하모닉 구조가 음성과 완전히 다름
3. **정보 손실**: 비선형 주파수 압축으로 엔진 주파수 패턴 왜곡

#### (3) 데이터 증강

```
원본 MAE: 0.54 → 증강 2x MAE: 0.55 (소폭 악화)
```

**왜 실패했는가?**

1. **이미 충분**: 594개가 단순 CNN에는 적당한 수준
2. **노이즈 추가 효과**: 증강이 오히려 원본 패턴을 흐리게 함
3. **증강 방법 부적합**: 시간 이동, 볼륨 변경이 엔진 품질과 무관

#### (4) 채널 결합 vs 분리 입력

```
논문 주장: 회귀에는 채널 결합이 더 좋다
실험 결과: Simple+CBAM (0.4819) > Channel Concat (0.4886)
          분리 입력이 오히려 더 좋음!
```

**왜 논문과 다른가?**

| 항목 | 논문 | 우리 프로젝트 |
|------|------|--------------|
| 출력 개수 | 1개 (NLI) | 5개 (점수) |
| 데이터 | 80대 차량 | 594개 오디오 |
| 태스크 | 소음 레벨 1~5 | 5가지 품질 점수 |
| 엔진 종류 | 디젤만 | 가솔린 93% + 디젤 7% |

**해석**: 5개 출력을 동시 예측할 때는 Full/Percussive 각각의 특징이 서로 다른 점수에 기여할 수 있음

## 3. CNN+CBAM이 "기대만큼" 동작하지 않은 이유

### 3.1 "성공"의 정의 재검토

```
MAE 0.48 = 1~5점 척도에서 ±0.48점 오차

실제 의미:
- 4점인 엔진을 3.5~4.5로 예측 → 합리적
- 하지만 3점 vs 4점 구분은 여전히 어려움
```

### 3.2 근본적 한계 분석

#### (1) 데이터 품질 문제

```
irregularity (불규칙성) MAE: 0.71
→ 1~5점에서 ±0.7점 오차
→ 사실상 예측 불가능 수준

이유:
- "불규칙성"은 시간에 따른 변동 패턴
- 5초 오디오의 스냅샷 스펙트로그램으로는 캡처 어려움
- 시계열 특성이 필요한데 CNN은 이미지로 처리
```

#### (2) 레이블 품질 문제

```
audable_range_score 분포:
  5점: ████████████████████████████████████████ 94%
  기타: ██ 6%

→ 거의 모든 데이터가 5점
→ 모델이 5만 예측해도 MAE 0.26 달성
→ 실제 학습이 아닌 분포 외우기
```

#### (3) 태스크 정의 문제

| 논문 (현대차) | 우리 프로젝트 |
|--------------|--------------|
| 고장 vs 정상 분류 | 정상 데이터만 존재 |
| 소음 레벨 1~5 (단일 지표) | 5개 점수 동시 예측 |
| 전문가 청음 평가 | 웹사이트 크롤링 데이터 |
| 통제된 환경 수집 | 다양한 조건의 데이터 |

**핵심 문제**:
> 우리는 "정상 엔진의 미세한 차이"를 예측하려 함
> 논문은 "정상 vs 고장의 명확한 차이"를 분류함

## 4. 의미있는 실험과 그 이유

### 4.1 가장 의미있는 실험: exp_005 (Simple+CBAM)

**의의**:
1. **최소 변경으로 최대 효과**: 기존 구조에 attention만 추가
2. **논문 기법의 실증적 검증**: 이론이 실제로 작동함을 확인
3. **오컴의 면도날**: 복잡한 것보다 단순한 것이 더 좋음

### 4.2 중요한 교훈을 준 실험: exp_002~004 (추가 특징)

**의의** (역설적으로):
```
"무엇이 안 되는지" 아는 것도 중요한 발견

발견: 594개 데이터에서는 특징 추가가 독이 됨
적용: 데이터 2000개 이상 확보 전까지 Simple 유지
```

### 4.3 데이터 인사이트를 준 실험: exp_007 (가솔린 전용)

**의의**:
```
가솔린 555개 (전체 555+39=594의 93%)
결과: 전체 사용과 거의 동일 (0.4884 vs 0.4819)

해석: 디젤 39개는 노이즈가 아니라 유용한 데이터
→ 더 많은 디젤 데이터 수집 권장
```

## 5. 왜 오디오 기반 CNN+CBAM이 한계가 있는가

### 5.1 입력 표현의 한계

```
오디오 → 스펙트로그램 변환 시 손실되는 정보:

1. 위상 정보 (Phase)
   - STFT magnitude만 사용
   - 위상에도 엔진 상태 정보 있음

2. 시간 해상도
   - 5초를 128×128 이미지로 압축
   - 순간적인 이상음 패턴 사라짐

3. 절대 크기 정보
   - dB 정규화로 절대 음량 손실
   - 엔진 상태와 음량은 연관됨
```

### 5.2 모델 구조의 한계

```
CNN의 특성:
- 지역적 패턴 인식에 강함 (커널)
- 전역적 의존성 캡처 어려움

엔진 품질 점수의 특성:
- 전체 스펙트로그램의 통계적 특성
- 시간에 따른 변화 패턴 (regularity)
- 특정 주파수 대역 간의 관계 (low_high_freq)

미스매치:
- CNN은 "어디에 특정 패턴이 있는가"를 학습
- 점수는 "전체적으로 얼마나 균일/다양한가"를 측정
```

### 5.3 CBAM의 역할과 한계

```
CBAM이 하는 일:
- Channel Attention: 어떤 주파수 대역이 중요한지
- Spatial Attention: 어떤 시간/주파수 위치가 중요한지

CBAM이 못하는 일:
- 시간에 따른 변화 패턴 학습
- 전역적 통계량 직접 모델링
- 위상 정보 복원

결론: CBAM은 CNN의 "집중력"을 높이지만, CNN 자체의 한계를 넘지 못함
```

|------|----------|--------|
| **Ordinal Regression Loss** | +5~10% | 낮음 |
| **Sample Weighting** | +3~5% | 낮음 |
| **앙상블 (3개 모델)** | +5~8% | 중간 |

```python
# Ordinal Regression 예시 (Coral Loss)
# 1~5점을 4개의 이진 분류로 변환
# P(y>1), P(y>2), P(y>3), P(y>4)
```

### 6.2 중기 (구조 변경)

| 방법 | 예상 효과 | 이유 |
|------|----------|------|
| **Transformer (ViT)** | +10~15% | 전역 의존성 학습 |
| **LSTM/GRU 추가** | +5~10% | 시계열 패턴 캡처 |
| **Multi-Scale CNN** | +5~8% | 다양한 시간 해상도 |

```
권장 구조:
[Spectrogram] → CNN → CBAM → LSTM → Dense → 5 outputs
                                ↑
                          시간 변화 학습
```

### 6.3 장기 (데이터 수집)

## 7. 핵심 결론

### 7.1 실험에서 배운 것

```
1. 단순함이 최고 (Simple CNN > Complex Models)
2. CBAM은 효과적 (+14.5%)
3. 특징 추가는 데이터 부족 시 역효과
4. 594개 데이터의 상한선에 근접 (MAE ~0.48)
```

### 7.2 오디오 기반 CNN+CBAM의 실제 성능

```
현재 성능: MAE 0.48 (1~5점에서 ±0.5점)
이론적 한계: MAE ~0.30 (같은 데이터, 완벽한 모델)
실용적 목표: MAE ~0.35 (±0.35점 = 실용 수준)

현재 → 목표까지 필요한 것:
1. 더 많은 데이터 (594 → 2000)
2. 시계열 모델 추가 (LSTM/Transformer)
3. 손실 함수 최적화 (Ordinal Regression)
```

### 7.3 프로젝트 방향 제안

```
Phase 4 권장 순서:

1. Ordinal Regression Loss 적용 (빠른 개선)
2. Sample Weighting으로 불균형 완화
3. 앙상블 (Simple+CBAM 3개 평균)
4. 추가 데이터 수집 (목표: 2000개)
5. Transformer 또는 LSTM 시도
```
