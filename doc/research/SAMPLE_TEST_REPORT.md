## 1. 테스트 개요

### 1.1 테스트 목적

스마트폰으로 녹음한 새 차량 엔진 오디오(M4A)를 기존 학습된 모델로 분석:
1. **Regression 모델**: 품질 점수 예측 (1~5점)
2. **VAE 모델**: 이상 탐지 (정상/이상)
3. **노이즈 필터링**: 배경 소음 제거 후 재평가

### 1.2 테스트 대상

| 차종 | 파일 수 | 비고 |
|------|---------|------|
| 디올뉴팰리세이드 | 4개 | 정상 차량 |
| 제네시스 | 4개 | **이상 차량 (의뢰자 확인)** |
| 코나 | 5개 | 정상 차량 |
| **합계** | **13개** | |

### 1.3 테스트 파라미터

| 항목 | 값 |
|------|-----|
| 샘플레이트 | 22,050 Hz |
| 세그먼트 길이 | 10초 |
| 입력 형상 | (128, 128, 4) |

## 3. 핵심 발견사항

### 3.1 문제점

```
⚠️ 제네시스(이상 차량)가 정상으로 분류됨

원인:
├─ 학습 데이터 2,000개가 모두 정상 차량
├─ 모델이 "정상 중 순위 매기기"만 학습
└─ 이상 데이터 없이는 이상 탐지 불가
```

### 3.2 모델별 분석

| 모델 | 현재 상태 | 문제 |
|------|-----------|------|
| Regression | 모든 파일 4.0+ 예측 | 정상만 학습해서 저점수 예측 불가 |
| VAE | 녹음 환경 차이 탐지 | 엔진 고장이 아닌 도메인 차이 탐지 |
| 노이즈 필터링 | 배경 소음 60% 감소 | 근본 문제 해결 안 됨 |

### 3.3 차종별 비교

| 차종 | 평균 Overall | 의도된 라벨 | 실제 판정 |
|------|-------------|-------------|-----------|
| 디올뉴팰리세이드 | 4.24 | 정상 | ✅ 정상 |
| **제네시스** | **4.35** | **이상** | **❌ 정상** |
| 코나 | 4.16 | 정상 | ✅ 정상 |

## 4. 근본 원인 분석

### 4.1 학습 데이터 문제

```
현대 인증중고차 웹사이트:
├─ "판매 가능한 차량"만 등록
├─ 이미 품질 검증 통과한 차량들
├─ 점수 4~5점 = 정상 중에서의 순위
└─ "이상 엔진"은 애초에 등록 안 됨
```

**점수 분포**:
- 4.5~5.0: 62%
- 4.0~4.5: 35%
- 3.5~4.0: 3%
- **3.5 미만: 0%** ← 이상 데이터 없음

### 4.2 결론

| 상황 | 설명 |
|------|------|
| 현재 | 정상 데이터만으로 학습 → "정상 순위"만 예측 가능 |
| 필요 | 이상 데이터 추가 → "정상 vs 이상" 분류 가능 |

## 5. 개선 방안

### 5.1 단기 (데이터 확보 필요)

| 항목 | 필요 수량 | 출처 |
|------|-----------|------|
| 이상 엔진 데이터 | 50~100개 | 정비소, 품질팀, 직접 녹음 |
| 정상 엔진 데이터 | 기존 유지 | 현대 웹사이트 (2,000+개) |

### 5.2 중기 (모델 재설계)

```
[현재] Regression 모델 → 품질 순위 예측
                ↓
[개선] 2단계 구조:
       1단계: Regression (품질 점수)
       2단계: Binary Classification (OK/NG)
              └─ 이상 데이터로 별도 학습
```

### 5.3 구현 완료 사항

| 항목 | 상태 | 위치 |
|------|------|------|
| 노이즈 필터링 | ✅ 완료 | `scripts/noise_filter_test.py` |
| 필터링된 오디오 | ✅ 생성 | `results/filtered_audio/` |
| Feature 추출기 | ✅ 구현 | `scripts/feature_anomaly_detector.py` |
