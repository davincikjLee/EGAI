# 2. 최적 설정값 (Production Ready)

## 2.1 모델 아키텍처

```python
# 최적 모델: Simple CNN + CBAM
# 파일: analysis/models.py → build_simple_cbam()

구조:
┌─────────────────────────────────────────────────────────────┐
│  Input (128, 128, 1)                                        │
│      ↓                                                      │
│  Conv2D(32) → BN → CBAM → MaxPool                          │
│      ↓                                                      │
│  Conv2D(64) → BN → CBAM → MaxPool                          │
│      ↓                                                      │
│  Conv2D(128) → BN → CBAM → MaxPool                         │
│      ↓                                                      │
│  Conv2D(256) → BN → CBAM → GlobalAvgPool                   │
│      ↓                                                      │
│  Dense(128) → Dropout(0.3)                                  │
│      ↓                                                      │
│  Dense(64) → Dropout(0.3)                                   │
│      ↓                                                      │
│  Dense(5) → Linear (5개 점수 출력)                          │
└─────────────────────────────────────────────────────────────┘

파라미터: ~500,000개
CBAM 추가 파라미터: ~24,000개 (5%)
```

## 2.2 전처리 파라미터

```python
# 파일: analysis/audio_preprocessing.py

class AudioPreprocessor:
    # 최적 설정
    sample_rate = 22050      # Hz
    n_fft = 2048             # FFT 윈도우
    hop_length = 512         # 홉 길이
    fmax = 6000              # 최대 주파수 (Hz)
    use_mel = False          # STFT 사용 (Mel 아님)

# 출력 스펙트로그램
# - Full Spectrogram: (freq_bins, time_frames)
# - Percussive Spectrogram: HPSS 분리된 타음 성분
# - 리사이즈: (128, 128) 고정
```

## 2.3 학습 설정

```python
# 파일: analysis/train_cv.py

# 최적 학습 파라미터
optimizer = Adam(learning_rate=0.001)
loss = 'mse'
metrics = ['mae']
batch_size = 32
epochs = 100

# 콜백
early_stopping = EarlyStopping(
    monitor='val_loss',
    patience=15,
    restore_best_weights=True
)

reduce_lr = ReduceLROnPlateau(
    monitor='val_loss',
    factor=0.5,
    patience=5,
    min_lr=1e-6
)

# Cross Validation
cv_folds = 5  # Stratified K-Fold
```

MAE 해석:
• 0.2 이하: 거의 정확 (분포 편향 가능)
• 0.3~0.5: 실용적 수준 (±0.5점 이내)
• 0.5~0.7: 참고 수준 (추가 개선 필요)

### 예측 난이도 원인

```
쉬움 (audable_range):
└── 94%가 5점 → 5만 예측해도 MAE ~0.3
└── 실제 학습보다 "분포 외우기"에 가까움

보통 (low_high_freq, mid_freq):
└── 주파수 도메인 특성 → CNN이 잘 캡처
└── 스펙트로그램에서 직접 관찰 가능

어려움 (regularity, irregularity):
└── 시간에 따른 변화 패턴 → CNN 한계
└── "얼마나 규칙적인가"는 시계열 분석 필요
└── Percussive 에너지 변동 → 복잡한 특징
```
