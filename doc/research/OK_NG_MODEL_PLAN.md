## 전문가 패널 합의 결론

### 방법론 선택

| 방법 | 장점 | 단점 | 권장도 |
|------|------|------|--------|
| **VAE (Variational AE)** | 확률 해석, 불확실성 추정, 정규화된 잠재 공간 | 학습 불안정 | ★★★★★ |
| **Convolutional AE** | 구현 간단 | 임계값 설정 어려움 | ★★★★ |
| **기존 회귀 모델 활용** | 이미 학습됨, 빠름 | 불확실성 추정 어려움 | ★★★★ |
| **Isolation Forest** | 빠름, 튜닝 적음 | 특징 추출 필요 | ★★★ |

## 새 차 데이터 검증 전략

### 검증 원칙

```
새 차 = 확실한 정상의 기준점

1. 새 차 99%+ 가 "정상" 판정되어야 함
2. 새 차 평균 이상점수 < 학습 데이터(중고차) 평균
3. 새 차 분포를 기준으로 임계값 설정
```

### 임계값 설정 공식

```python
threshold = max(
    new_car_mean + 3 * new_car_std,  # 새 차 99.7% 커버
    new_car_max * 1.5                 # 새 차 최대값 + 마진
)
```

## 기존 회귀 모델 활용 방법

### MC Dropout 불확실성 추정

```python
def predict_with_uncertainty(model, spectrogram, n_samples=30):
    """
    정상: 예측 분산 낮음
    이상: 예측 분산 높음 (모델이 "혼란스러움")
    """
    predictions = []
    for _ in range(n_samples):
        pred = model(spectrogram, training=True)  # Dropout 활성화
        predictions.append(pred)

    mean_pred = np.mean(predictions, axis=0)
    std_pred = np.std(predictions, axis=0)

    uncertainty = np.mean(std_pred)  # 이상 지표
    return mean_pred, uncertainty
```

### 점수 불일치 감지

```python
def score_consistency(predictions):
    """
    정상: 5개 점수 비슷 (대부분 4-5점)
    이상: 점수 간 불일치 (일부만 낮음)

    예: [4.5, 4.2, 4.8, 4.3, 2.1] → 불일치 높음 → 의심
    """
    consistency = 1 - np.std(predictions) / np.mean(predictions)
    return consistency
```

## 구현 로드맵

### Phase 1: 기반 구축

```
1. Convolutional VAE 구현
   - Encoder: 기존 CBAM Feature Extractor 재활용
   - Decoder: 새로 설계
   - Loss: Reconstruction + β*KL

2. 학습 데이터 준비
   - 기존 2,234건 중 4-5점 데이터 (약 2,000건)
   - 5-Fold CV 준비

3. 새 차 데이터 확보 계획
   - 수집 채널 정의
   - 목표: 최소 50건
```

### Phase 2: 모델 학습 및 검증

```
1. VAE 학습
   - β 튜닝 (0.1 ~ 1.0)
   - Early stopping on validation recon loss

2. 기존 회귀 모델 활용
   - MC Dropout 불확실성 추정 추가
   - 점수 불일치 지표 계산

3. 앙상블 가중치 실험
   - VAE 점수 + 불확실성 + 불일치
   - 최적 조합 탐색
```

### Phase 3: 새 차 데이터 검증

```
1. 새 차 데이터 수집 완료

2. 검증 실험
   - 새 차 99%+ 정상 판정 확인
   - 새 차 평균 < 중고차 평균 확인

3. 임계값 설정
   - 새 차 분포 기반 계산
   - 보수적 마진 적용
```

### Phase 4: 테스트 및 배포

```
1. 합성 이상 데이터 테스트
   - 노킹, 노이즈, 왜곡 합성
   - 탐지율 측정

2. 추론 API 개발
   - 입력: 오디오 파일
   - 출력: 정상/주의/점검권장 + 신뢰도

3. 모니터링 대시보드
   - 입력 분포 모니터링
   - 예측 분포 추적
```
