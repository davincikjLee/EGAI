## 3. 전처리 파라미터

### 3.1 오디오 설정

| 파라미터 | 값 | 설명 |
| ---- | ---- | ---- |
| Sample Rate | 22,050 Hz | 현대차 웹사이트와 동일 |
| FFT Size | 2,048 | 주파수 해상도 ~10.77 Hz |
| Hop Length | 512 | 시간 해상도 ~23ms |
| Max Frequency | 6,000 Hz | 엔진음 핵심 대역 |

### 3.2 세그먼트 추출

| 파라미터 | 값 | 설명 |
| ---- | ---- | ---- |
| 세그먼트 길이 | **10초** | 현대차 웹사이트 음원과 동일 |
| 세그먼트 수 | **5개** | 파일당 |
| 오프셋 간격 | 2초 | 중앙 기준 ±4초 범위 |

### 3.3 세그먼트 추출 방식

```text
전체 오디오 (예: 30초)
[==============중앙(15초)==============]

세그먼트 추출 (중앙 기준):
  세그먼트 1: [11초 ~ 21초] (중앙-4초)
  세그먼트 2: [13초 ~ 23초] (중앙-2초)
  세그먼트 3: [15초 ~ 25초] (중앙)
  세그먼트 4: [17초 ~ 27초] (중앙+2초)
  세그먼트 5: [19초 ~ 29초] (중앙+4초)
```

## 4. 스펙트로그램 구성

### 4.1 4채널 입력

| 채널 | 설명 | 용도 |
| ---- | ---- | ---- |
| CH1: Full | 전체 스펙트로그램 | 주파수 특성 |
| CH2: Percussive | 타악음 성분 | 충격음 (노킹) |
| CH3: Difference | 시간 변동 | 급격한 변화 |
| CH4: Variance | 불안정 영역 | 불규칙성 |

### 4.2 출력 형상

- 단일 세그먼트: `(128, 128, 4)`
- 배치 (5개 세그먼트): `(5, 128, 128, 4)`

---

## 5. 사용 모델

### 5.1 Regression 모델 (품질 점수)

| 항목 | 값 |
| ---- | ---- |
| 모델 타입 | 4channel_cbam (Multi-head CBAM) |
| 입력 | (128, 128, 4) |
| 출력 | 5개 품질 점수 |
| 성능 | MAE 0.3463 (±0.009) |
| 경로 | `experiments/best_model_4channel_cbam_1.keras` |

**출력 점수**:

- `low_high_freq`: 저/고주파 균형
- `mid_freq_score`: 중주파 품질
- `audible_range_score`: 가청 범위
- `regularity`: 규칙성
- `irregularity`: 불규칙성
- `overall`: 종합 점수 (5개 평균)

### 5.2 VAE 모델 (이상 탐지)

| 항목 | 값 |
| ---- | ---- |
| 모델 타입 | Variational Autoencoder |
| 잠재 공간 | 128차원 |
| VAE Score | 154.66 ± 25.45 |
| Encoder | `experiments/20260124_013112_530a70/vae_encoder.keras` |
| Decoder | `experiments/20260124_013112_530a70/vae_decoder.keras` |

**이상 점수 계산**:

```text
VAE Score = Reconstruction Error + β × KL Divergence
```

## 6. 판정 기준

### 6.1 Regression 기준 (품질 점수)

| Overall 점수 | 판정 | 설명 |
| ---- | ---- | ---- |
| 4.5 ~ 5.0 | 우수 | 엔진 상태 매우 양호 |
| 4.0 ~ 4.5 | 양호 | 엔진 상태 좋음 |
| 3.5 ~ 4.0 | 보통 | 일반적인 수준 |
| 3.0 ~ 3.5 | 주의 | 점검 권장 |
| < 3.0 | 경고 | 정밀 점검 필요 |

### 6.2 VAE 기준 (이상 탐지)

| VAE Score | 판정 |
| ---- | ---- |
| < 200 | 정상 (OK) |
| 200 ~ 250 | 주의 |
| > 250 | 이상 (NG) |

> 임계값은 Phase 3 (새 차 데이터)에서 최종 보정 예정

## 8. 결과 해석

### 8.1 세그먼트 간 일관성

- **표준편차 < 0.2**: 안정적인 엔진음
- **표준편차 > 0.3**: 불안정, 추가 분석 필요

### 8.2 Regression vs VAE 불일치

| Regression | VAE | 해석 |
| ---- | ---- | ---- |
| 양호 (>4.0) | 정상 | 확실히 정상 |
| 양호 (>4.0) | 이상 | 학습 데이터에 없는 패턴 |
| 불량 (<3.5) | 정상 | 점수는 낮지만 정상 범위 |
| 불량 (<3.5) | 이상 | 확실히 이상 |
