# EGAI 서비스 전략 문서

**작성일**: 2026-01-14
**버전**: v1.0

---

## 1. 프로젝트 배경

### 기술 현황
- **모델**: Multi-head CBAM (MAE 0.4578)
- **데이터**: 현대 인증 중고차 2,236건 (대부분 4~5점)
- **한계**: 낮은 점수(1~2점) 데이터 부족으로 이상치 예측 신뢰도 낮음

### 데이터 불균형 현황
```
irregularity 분포:
  2점:    9개 ( 1.6%)  ← 극소수
  3점:   80개 (14.6%)
  4점:  118개 (21.5%)
  5점:  341개 (62.2%)  ← 대다수
```

## 2. 서비스 포지셔닝 전환

| AS-IS | TO-BE |
|-------|-------|
| "엔진 품질 점수 예측" | **"엔진 상태 안심 인증"** |
| 1~5점 전 구간 예측 | 양호 상태 확인에 집중 |
| 기술 중심 | 사용자 가치 중심 |

### 핵심 원칙
> **"모르는 것을 아는 척하지 않는다"**
> - 기술적으로 자신 있는 영역만 서비스화
> - 불확실한 영역은 "점검 권장"으로 전환

---

## 3. 유저 스토리

```
1. 사용자가 자기 차량 엔진 평가 원함
2. 앱 설치 또는 음성 파일 업로드
3. [무료] 1차 분석: "안심 범위" vs "점검 권장"
4. "안심 범위"인 경우 유료 결제 유도
5. [유료] 상세 스코어 제공
   - 현대 인증 중고차 기준 상대적 위치
   - "상위 20%", "평균 수준" 형태로 표현
```

## 4. 서비스 아키텍처

### 하이브리드 모델 구조

```
┌────────────────────────────────────────────────────────┐
│                    EGAI 서비스 구조                     │
├────────────────────────────────────────────────────────┤
│                                                        │
│  [녹음/업로드]                                         │
│        ↓                                               │
│  [Stage 1: Autoencoder 이상탐지]                       │
│  └── 4~5점 데이터로만 학습                             │
│  └── Reconstruction Error 기반                         │
│        ↓                                               │
│    ┌───┴───┐                                          │
│    ↓       ↓                                          │
│ "안심"   "점검 권장"                                   │
│    ↓       ↓                                          │
│ [유료]   [무료 종료]                                   │
│    ↓       └── 정비소 연결                            │
│    ↓                                                   │
│  [Stage 2: CNN+CBAM 상세 스코어]                       │
│  └── 4~5점 범위 내 세분화                             │
│  └── "상위 10% / 평균 / 하위 30%" 형태                │
│                                                        │
└────────────────────────────────────────────────────────┘
```

### 모델별 역할

| Stage | 모델 | 입력 데이터 | 출력 | 신뢰도 |
|-------|------|------------|------|--------|
| 1 | Autoencoder | 4~5점 (550+개) | 정상/이상 | 높음 |
| 2 | Multi-head CBAM | 4~5점 범위 | 상세 점수 | 중상 |

## 6. 수익 모델

### 가격 정책

| Tier | 가격 | 기능 | 마진 |
|------|------|------|------|
| **무료** | 0원 | 1차 스크리닝 (정상/점검권장) | - |
| **기본** | 9,900원 | 상세 리포트 1회 + PDF | 80% |
| **프리미엄** | 29,900원/년 | 월 1회 정기 점검 + 변화 알림 | 85% |

### B2B 확장

```
[B2B 수익원]
├── 중고차 딜러 API 제공 (건당 과금)
├── 보험사 연동 (보험료 할인 연계)
└── 정비소 파트너십 (수수료 모델)
```

### 수익 전략 핵심
- **"이상" 판정은 무료** → 법적 리스크 최소화
- **"안심" 판정만 유료화** → 자신 있는 영역에서 수익

## 7. 리스크 관리

### 법적 리스크

| 시나리오 | 리스크 | 대응 |
|---------|--------|------|
| 정상 판정 → 실제 고장 | 높음 | 면책 조항 + 보험 검토 |
| 이상 판정 → 실제 정상 | 중간 | 환불 정책 (재측정 무료) |
| 점검 권장 → 고객 불만족 | 낮음 | 무료 서비스로 제공 |

### 면책 조항 예시
```
본 서비스는 AI 기반 참고용 분석 결과이며,
실제 차량 상태와 다를 수 있습니다.
정확한 진단은 공인 정비소에서 받으시기 바랍니다.
```

## 8. 로드맵

### Phase 1: MVP (3개월)
- **목표**: 서비스 검증
- **기능**: 1차 스크리닝만 (무료)
- **모델**: Autoencoder 이상탐지
- **KPI**: DAU 1,000명, 재측정율 40%

### Phase 2: 수익화 (6개월)
- **목표**: PMF 달성
- **기능**: 유료 상세 리포트 추가
- **모델**: 하이브리드 (AE + CNN)
- **KPI**: 유료 전환 15%, MRR 500만원

### Phase 3: 확장 (12개월)
- **목표**: 시장 확대
- **기능**: B2B API, 정기 구독
- **데이터**: 이상 케이스 라벨링 (정비소 협력)
- **KPI**: B2B 계약 10건, ARR 2억원

### Phase 4: 고도화 (18개월+)
- **목표**: 기술 차별화
- **기능**: 고장 유형 분류
- **데이터**: 정비 이력 연동
- **KPI**: 고장 예측 정확도 80%+

## 10. 핵심 결론

### 기술적 한계를 비즈니스로 해결

| 문제 | 기술적 한계 | 비즈니스 솔루션 |
|------|------------|----------------|
| 저점수 예측 불가 | 데이터 부족 | "점검 권장"으로 전환 |
| 이상치 신뢰도 낮음 | 학습 불가 | 무료 제공 + 정비소 연결 |
| 구체적 점수 부정확 | MAE 0.5 | 상대적 위치로 표현 |

### 서비스 핵심 가치

> **"당신의 엔진이 현대 인증 중고차 수준인지 확인해드립니다"**

- 절대적 점수 (X) → 상대적 위치 (O)
- 이상 진단 (X) → 안심 인증 (O)
- 기술 과시 (X) → 사용자 가치 (O)
