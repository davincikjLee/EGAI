## 핵심 견해

## 상세 분석

### 1. 기술적 가능성 (모델 관점)

```
학습 분포: [3, 4, 5] 점
추론 요청: [1, 2] 점 (분포 외)

문제점:
┌─────────────────────────────────────────────────────┐
│  Regression 모델은 학습 데이터 분포 내에서만 신뢰성  │
│  분포 외(Out-of-Distribution) 예측 = Extrapolation  │
│  → 신뢰구간이 급격히 넓어짐                          │
│  → 예측값의 신뢰도 급감                              │
└─────────────────────────────────────────────────────┘
```

### 2. 데이터 파이프라인 관점

```python
# 현재 파이프라인
정상 오디오 → 스펙트로그램 → CNN → [3.5, 4.2, 4.8, 4.0, 3.1] 예측

# 불량 오디오 (가상)
불량 오디오 → 스펙트로그램 → CNN → [???, ???, ???, ???, ???]
                                    ↑
                              학습되지 않은 패턴
                              모델이 무작위 출력 가능
```

### 3. 대안적 접근법

| 방법 | 설명 | 적합도 |
|------|------|--------|
| **One-Class SVM** | 정상만 학습, 정상 경계 밖 = 이상 | ⭐⭐⭐⭐ |
| **Autoencoder** | 정상 복원 학습, 복원 에러 = 이상 | ⭐⭐⭐⭐⭐ |
| **Isolation Forest** | 정상 패턴에서 고립된 샘플 탐지 | ⭐⭐⭐ |
| **Mahalanobis Distance** | 정상 분포 중심에서 거리 측정 | ⭐⭐⭐ |

### 4. 권장 아키텍처

```
[정상 데이터] → [Autoencoder 학습]
                     ↓
              정상 패턴 압축/복원 학습
                     ↓
[새 오디오] → [Encoder] → [Decoder] → [복원 오디오]
                                           ↓
                              원본과 비교 → 복원 에러
                                           ↓
                              에러 크면 = "이상"
                              에러 작으면 = "정상"
```

### 3. 정량적 특징 추출

```python
# 정상 엔진의 특징 분포 (가상)
정상_spectral_flatness = N(μ=0.2, σ=0.05)  # 순음에 가까움
정상_harmonic_ratio = N(μ=0.8, σ=0.1)       # 하모닉 우세
정상_zcr = N(μ=0.1, σ=0.02)                 # 낮은 ZCR

# 불량 엔진 예상 특징
불량_spectral_flatness = 0.6~0.8  # 노이즈 증가

불량_zcr = 0.3~0.5                # 높은 ZCR

# 탐지 방법: 정상 분포에서 3σ 이상 벗어나면 이상
if spectral_flatness > μ + 3σ:
    flag_anomaly()
```

### 4. HPSS 기반 이상 탐지

```
HPSS 출력:
- Harmonic: 규칙적 톤 성분
- Percussive: 충격/타음 성분

정상 엔진: Harmonic >> Percussive
불량 엔진: Percussive 증가 (노킹, 이상 타음)

탐지 지표:
Percussive_Ratio = E(Percussive) / E(Full)

정상: 0.1~0.3
주의: 0.3~0.5
위험: 0.5 이상
```

#### (B) Contrastive Learning

```
아이디어: 정상 샘플들은 서로 가깝게, 이상은 멀리

1. 정상 데이터로 표현 학습
2. 새 샘플의 "정상 중심"으로부터 거리 측정
3. 거리 > 임계값 → 이상

장점: 레이블 없이 학습 가능
```

#### (C) Self-Supervised Pre-training

```
1. 정상 데이터로 사전학습 (Self-Supervised)
   - 마스킹 후 복원
   - 시간 순서 예측
   - Contrastive 학습

2. 학습된 표현으로 이상 탐지
   - 정상 클러스터 형성
   - 클러스터 외 = 이상
```

# 📊 Expert 5: 실험설계/통계 전문가

## 핵심 견해
> "통계적으로 Extrapolation은 **신뢰구간이 폭발적으로 확대**됩니다. 권장하지 않습니다."

## 상세 분석

### 1. Extrapolation의 통계적 위험

```
선형 회귀 y = β₀ + β₁x의 예측 구간:

ŷ ± t_{α/2} × SE × √(1 + 1/n + (x-x̄)²/Σ(xᵢ-x̄)²)
                        ↑
              x가 x̄에서 멀어질수록 급격히 증가

현재 상황:
- 학습 데이터 x̄ ≈ 4.0 (평균 점수)
- 예측 대상 x = 1.5 (불량)
- (x - x̄)² = (1.5 - 4.0)² = 6.25

→ 예측 구간이 학습 범위의 6배 이상 넓어짐
→ 실질적으로 "예측 불가"
```

### 2. Selection Bias 분석

```
┌─────────────────────────────────────────────────────┐
│                  데이터 수집 과정                     │
├─────────────────────────────────────────────────────┤
│                                                     │
│  전체 차량 모집단                                    │
│  ┌─────────────────────────────────────────┐        │
│  │  정상    │  경미한 문제  │  심각한 문제  │        │
│  │   70%    │     20%      │     10%      │        │
│  └─────────────────────────────────────────┘        │
│                    ↓                                │
│           인증중고차 필터링                          │
│           (품질 검사 통과)                           │
│                    ↓                                │
│  ┌─────────────────────────────────────────┐        │
│  │  정상    │  경미한 문제  │                │        │
│  │   93%    │     7%       │   (탈락)      │        │
│  └─────────────────────────────────────────┘        │
│                    ↓                                │
│           우리 데이터셋 (594개)                      │
│           → 심각한 문제(1~2점) = 0%                  │
│                                                     │
│  결론: Selection Bias로 인해 불량 데이터 존재 불가   │
│       모델이 불량을 "모르는" 것은 데이터 문제        │
└─────────────────────────────────────────────────────┘
```

### 5. 가설 검정 설계

```
귀무가설 H₀: "정상 데이터로 학습한 모델은 불량을 탐지할 수 없다"
대립가설 H₁: "정상 데이터로 학습한 모델이 불량을 탐지할 수 있다"

검정 방법:
1. 정상 데이터로 Anomaly Detection 모델 학습
2. 합성 불량 데이터 100개 생성
3. 탐지율(Recall) 측정

기각 기준:
- 탐지율 > 70%이면 H₀ 기각
- 우연 수준(50%) 대비 유의미한 차이 필요
- p-value < 0.05
```

# 🎯 종합 토론: 전문가 합의점

## 합의된 결론

### 1. Regression Extrapolation → ❌ 권장하지 않음

```
모든 전문가 동의:
- 학습 분포 밖 예측은 신뢰할 수 없음
- 불량 패턴이 정상의 연장선이라는 가정 자체가 틀림
- 통계적 신뢰구간 폭발적 확대
```

### 2. 대안: Anomaly Detection → ✅ 권장

```
MLOps + 오디오AI 동의:
- Autoencoder 기반 이상 탐지
- 정상 패턴만 학습 → 복원 에러로 이상 판별
- One-Class Classification 접근
```

### 3. 불량 패턴 정의 가능 → ⚠️ 조건부 가능

```
엔진 전문가 + 오디오 전문가 동의:
- 고장 유형별 특징적 패턴 존재
- 물리적 시뮬레이션으로 합성 가능
- 단, 실제 불량 데이터 검증 필수
```

### 4. 데이터 수집 전략 → 필수

```
통계 전문가 강조:
- Selection Bias 인식
- 불량 데이터 최소 100개 수집 권장
- 정비소/인증 실패 차량 협력 필요
```
