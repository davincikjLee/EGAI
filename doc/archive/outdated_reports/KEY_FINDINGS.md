### 클래스 불균형

```
audable_range_score 분포:
  5점: ████████████████████████████████████████ 94%

```

### 의미

- 현재 데이터는 **모두 정상 엔진** (고장 데이터 없음)
- 불균형한 점수로 인해 **일부 점수는 예측 의미 없음**
- `audable_range_score` MAE 0.26은 **모델 성능이 아닌 데이터 편향**

## 5. 5-Fold Cross Validation의 중요성

### 단일 분할 vs 5-Fold CV

```
단일 분할 (Train/Val 80/20):
  → 검증 세트에 따라 성능 크게 변동
  → 운 좋으면 좋은 결과, 나쁘면 나쁜 결과

5-Fold Cross Validation:
  → MAE: 0.5635 ± 0.0948
  → 표준편차(±0.0948)로 안정성 확인 가능
  → 모든 데이터가 한 번씩 검증에 사용됨
```

### 실제 Fold별 결과 (Baseline)

| Fold | MAE | 특징 |
|------|-----|------|
| 1 | 0.48 | 가장 좋음 |
| 2 | 0.55 | 평균 |
| 3 | 0.62 | 평균 |
| 4 | 0.58 | 평균 |
| 5 | 0.59 | 평균 |

### 의미

- **±0.0948**의 표준편차는 모델이 **데이터에 따라 변동**함을 의미
- 단일 실험 결과만 보면 오해할 수 있음
- CV로 **신뢰할 수 있는 성능 측정** 가능

## 7. 회귀 vs 분류 전환의 효과

### 원본 (분류)
```

```

### 현재 (회귀)
```
입력: 엔진 오디오
```

- 회귀로 전환하여 **세부 진단 가능**
